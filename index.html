PDF Q&A Assistant

Upload any PDF — a research paper, a legal document, an internal report — and ask questions about its contents. The system extracts text page-by-page, chunks it, embeds it locally, retrieves the most relevant passages, and generates an answer with page-level citations so you can verify every claim against the source.

Upload PDF→ pdfplumber→ Chunk (500 tok)→ Embed→ Chroma→ Ollama→ Answer + citations
Try the UI · demo mode Read the docs Source
CitationsEvery answer includes source excerpts labeled by page number, so you can jump to the exact location in the PDF.
Hybrid retrievalSemantic similarity + keyword overlap scoring (alpha=0.6) for better recall on specific queries.
Local-firstpdfplumber for extraction, sentence-transformers for embeddings, Chroma for storage — all running locally, no cloud calls.
Project 02 FastAPI Ollama Chroma youtube-transcript-api sentence-transformers

YouTube Research Assistant

Paste a YouTube URL and ask questions about the video's transcript. The system fetches the transcript (free, no API key required), chunks it with timestamp labels, embeds it locally, and generates answers with timestamp citations (MM:SS) so you can jump to the exact moment in the video.

YouTube URL→ transcript-api→ Chunk (timestamps)→ Embed→ Chroma→ Ollama→ Answer + timestamps
Try the UI · demo mode Read the docs Source
TimestampsEvery answer includes transcript excerpts labeled with MM:SS timestamps, so you can jump to the exact moment in the video.
Free transcript APIUses youtube-transcript-api — no YouTube Data API key, no quota, no cost. Works on most videos with captions.
Timeline visualThe frontend shows a transcript timeline with clickable markers so you can navigate the video's content visually.

Output
1
Ingest the source
PDF: extract text page-by-page with pdfplumber. YouTube: fetch transcript with youtube-transcript-api (free, no key).
2
Chunk with source labels
Split text into overlapping 500-token segments. Each chunk carries its page number (PDF) or timestamp (YouTube) for citation.
3
Embed and store
Convert chunks to vectors with sentence-transformers (all-MiniLM-L6-v2, runs on CPU). Store in a local Chroma collection with cosine similarity.
4
Retrieve + hybrid search
On query: embed the question, find similar chunks in Chroma, combine with keyword overlap scoring for better recall.
5
Generate with citations
Build a RAG prompt with retrieved context + explicit citation instructions. Call Ollama (llama3.2). Format citations for the frontend.
6
Serve via FastAPI + frontend
REST API with CORS. Minimal HTML/CSS/JS frontend. Demo mode for presentation, live mode when backend is deployed.

Run it yourself

Prerequisites

# Install Ollama and pull a model
brew install ollama
ollama pull llama3.2
ollama list   # verify it's running

PDF Q&A Assistant

# From the monorepo root
cd pdf-qa
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env
python -m pdf_qa.main    # → http://localhost:8000
open frontend/index.html

YouTube Research Assistant

# From the monorepo root
cd youtube-rag
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env
python -m youtube_rag.main  # → http://localhost:8001
open frontend/index.html

Run both together

python -m pdf_qa.main &     # → :8000
python -m youtube_rag.main   # → :8001

Docker

# Build and run PDF Q&A (Ollama must be reachable)
docker build -t pdf-qa -f pdf-qa/Dockerfile .
docker run -p 8000:8000 -e OLLAMA_BASE_URL=http://host.docker.internal:11434 pdf-qa

# Build and run YouTube RAG
docker build -t youtube-rag -f youtube-rag/Dockerfile .
docker run -p 8001:8001 -e OLLAMA_BASE_URL=http://host.docker.internal:11434 youtube-rag
Note on GitHub Pages: The portfolio site and the tool frontends are static HTML — they host for free on GitHub Pages. The backends (FastAPI + Ollama + Chroma) run locally on your machine. The frontends default to calling localhost:8000 and localhost:8001. When you open the GitHub Pages URL on the same machine, it hits your local backend — no API keys, no paid endpoints, nothing leaves your machine.
